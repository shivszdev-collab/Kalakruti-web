KALAKRUTI TEXTILES WEBSITE

Files:
- index.html: website content
- style.css: responsive layout and brand styling
- script.js: mobile menu, collection search, enquiry buttons, current year
- images/: place your own product photos here if you prefer local images

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in Chrome to preview.
3. Replace the illustrative image URLs in index.html and style.css with actual saree photos.
4. Add the store's phone number and WhatsApp number in the footer and WhatsApp links.
   For WhatsApp, use international format without +, spaces or dashes, e.g. 91XXXXXXXXXX.
5. Upload the files to your hosting provider's public_html folder.

NOTE
This is a front-end starter website. It does not include an online payment gateway, product database, stock management, or admin panel. Search and enquiry interactions work in the browser. Google Fonts and image URLs need internet access.
